## ローカルでの確認

```bash
mkdocs serve   # http://127.0.0.1:8000 で確認
```

## PDF 生成

```bash
# MkDocs PDF (site/pdf/document.pdf)
mkdocs build

# TeX PDF (tex/out/main.pdf)
cd tex && make
```
